# Hemera (C++26)

یک کلاینت فوق‌سریع، سبک و کاملاً بومی (Native) برای ویندوز با استفاده از استاندارد **C++26** و **Win32 API** بدون هرگونه وابستگی یا فریم‌ورک‌های سنگین (کاملاً بدون Qt، بدون وب‌ویو، بدون Electron).

---

## ویژگی‌ها و معماری (Architecture & Features)

### ۱. معماری بومی و سبک (Pure Native C++26)
- **بدون Qt و بدون کتابخانه‌های سنگین:** رابط کاربری مستقیماً بر پایه‌ی Windows Win32 API پیاده‌سازی شده و از DWM Immersive Dark Mode برای هماهنگی با تم تاریک ویندوز ۱۰ و ۱۱ بهره می‌برد.
- **تک فایل اجرایی فوق‌العاده بهینه:** مصرف رم کمتر از ۱۵ مگابایت با رندرینگ روان (تا ۱۲۰ فریم بر ثانیه).
- **سی‌پلاس‌پلاس مدرن:** استفاده از قابلیت‌های مدرن C++26، معماری چندنخی بهینه، زمان‌بندی دقیق و مدیریت حافظه ایمن.

### ۲. امکانات و قابلیت‌ها (Features)
- **پروتکل‌های پیشرفته:** MASQUE ،WireGuard ،WARP-in-WARP (gool) و MASQUE-in-MASQUE (mim).
- **مودهای اسکن:** Turbo ،Balanced ،Thorough ،Verified و Ironclad.
- **مدیریت سیستم‌پروکسی ویندوز (SysProxy):**
  - تنظیم پروکسی محلی روی رجیستری ویندوز (`HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings`).
  - فعال‌سازی آنی با `InternetSetOptionW` بدون نیاز به ریستارت مرورگرها.
  - پشتیبان‌گیری و بازیابی خودکار تنظیمات پس از قطع اتصال یا بسته شدن برنامه.
- **جلوگیری از پروسه‌های معلق (Windows Job Objects):**
  - استفاده از Job Object برای اطمینان از پاکسازی تمام زیرپروسه‌ها در صورت خروج ناگهانی.
- **سینی سیستم (System Tray):**
  - اجرای در پس‌زمینه با سینی سیستم و منوی مدیریت سریع (Connect/Disconnect، وضعیت، خروج).
- **کنسول لاگ زنده:** با قابلیت کپی در کلیپ‌بورد و اسکرول روان.

## ساختار پروژه

```
Hemera/
├── include/            # هدرهای اصلی برنامه و مدل‌های داده

│   ├── src/            # پیاده‌سازی هسته
│   └── vendor/         # کتابخانه‌ها و وابستگی‌های بهینه

└── README.md
```

## نحوه ساخت (Build Instructions)

### روش اول: استفاده از `build.bat`
در محیط **Developer Command Prompt for VS 2022** دستور زیر را اجرا کنید:

```cmd
build.bat
```

### روش دوم: استفاده از CMake

```cmd
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

فایل نهایی در مسیر `build/Release/Hemera.exe` ایجاد خواهد شد.
